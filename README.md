Cybersecurity Log Analyzer

About

Cybersecurity Log Analyzer is a Java-based project that reads application log files, detects repeated failed login attempts, and generates security alerts.

Technologies Used

- Java 25.0.1
- VS Code
- MySQL (planned)
- JDBC (planned)
- JavaFX (planned)

Features

- Reads log files
- Detects failed login attempts
- Identifies suspicious IP addresses
- Generates security alerts

How to Run

1. Install Java JDK 25.0.1.
2. Open the project in VS Code.
3. Compile and run the Java program.

Future Enhancements

- MySQL database integration
- JavaFX dashboard
- Advanced security alerts

Purpose
